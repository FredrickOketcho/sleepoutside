Think about it

Why use data attributes?
They keep small pieces of element-specific data alongside the HTML element, where JavaScript and CSS can access them.
How do they support accessibility?
They do not add accessibility by themselves. Pair them with semantic HTML, keyboard-operable controls, and clear status updates, as this example does.
When are they a good fit?
Use them for small client-side values tied to an element, such as an item ID or category. Use application state or a data service for larger or frequently changing records.
How can data be kept valid and secure?
Validate values against expected formats, treat browser-provided data as untrusted, and avoid inserting it as HTML. This example renders values as text.
