Privacy notice

What this project handles when you browse or create an account.

This student project does not sell personal information. It does not currently use an account database for route favorites, and the fare request form does not deliver requests to a transport operator.

Account details

If account registration is enabled, your name and email address are processed by Firebase Authentication. Firebase handles password authentication; this project does not send passwords to its own server or store them. You can contact the project owner to request help with account deletion.

Information kept in your browser

Saved routes and stages, recent searches, map position, cached search results, the selected color theme, and (if you enter one) your Transitland API key may be stored in this browser's local storage. This information is not currently synced to an account. Clear this site's browser storage to remove it.

Third-party services

Place searches and map clicks are sent to OpenStreetMap's Nominatim service. Map tiles are loaded from OpenStreetMap. Nearby feed stop requests are sent to Transitland when a visitor configures an API key. Each service may process request data under its own policies; see the Attributions page for links.

Fare request form

The current form submits its fields in the page URL to a local confirmation page. They may remain in browser history and normal hosting request logs, so avoid entering sensitive information. The form does not send requests to a transport provider or store them in an account.
